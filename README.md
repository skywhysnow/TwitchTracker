# Twitch Tracker на Rust

Переписывание Twitch Tracker с Python на Rust. Сейчас готово **ядро**: вся логика без интерфейса,
покрытая тестами. База SQLite полностью совместима с Python-версией, поэтому Rust-версия откроет ту же папку
`%APPDATA%\TwitchTracker` и подхватит каналы, группы, настройки, историю эфиров и расписания.

## Что в ядре (`crates/core`)
| Модуль | Что делает |
| --- | --- |
| `prediction` | прогноз следующего эфира: расписание Twitch и привычки за 8 недель, уровень вероятности |
| `events` | сравнение двух проверок: начало эфира, конец, смена категории и названия, защита от ложных срабатываний |
| `policy` | правила уведомлений: типы событий, избранные, тихие часы, настройки каналов |
| `quiet_digest` | сводка после тихих часов |
| `stats` | статистика эфиров за период |
| `history_import` | разбор архива эфиров (видео) и расписания из ответов Twitch |
| `backup` | экспорт и импорт резервной копии (токены не включаются) |
| `repository` | база SQLite, схема и миграции совпадают с Python-версией |
| `models`, `stream` | общие типы: канал, событие, идущая трансляция |

Тексты для пользователя в ядре не формируются: интерфейс получает данные и коды причин и сам подбирает язык.

## Проверка
```
cargo test --workspace
```
Тест `python_compat` читает базу, созданную Python-версией (`tests/fixtures/python_v06.db`).
Обратное направление проверяется переменной `TT_COMPAT_OUT=путь.db`: тест создаёт базу, которую затем открывает Python.
